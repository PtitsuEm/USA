## 🔍 О проекте

В репозитории собрана база данных из более чем **10 000 проверенных публичных должностных лиц США**:
- **Губернаторы (55)** всех 50 штатов и 5 территорий со ссылками на официальные приёмные и порталы обращений.
- **Вице-губернаторы и конституционные преемники (55)** с прямыми контактами и графом подчинения.
- **Конгресс США (541)**: Сенаторы и члены Палаты представителей с профилями и комитетами.
- **Законодательные собрания штатов (7 400+)**: сенаторы штатов и члены палат представителей всех 50 штатов с официальными `.gov` адресами и телефонами.
- **Руководство экономического развития (EDA Heads)**: 55 директоров департаментов экономического развития штатов.
- **Мэры и муниципальные лидеры**: мэры 50 крупнейших мегаполисов и столиц, а также руководители муниципалитетов.
- **Федеральное руководство**: ключевые фигуры кабинета и энергетического сектора (DOE, SelectUSA, Commerce).

Каждая запись содержит прямую ссылку на официальный первоисточник (`.gov`, парламентский реестр, SelectUSA), дату последней проверки и статус верификации.

## 🚀 Быстрый старт (Инструкция по запуску сайта)

### 1. Клонирование репозитория

Склонируйте репозиторий на свой компьютер через терминал:

```bash
git clone https://github.com/PtitsuEm/USA.git
cd USA
```

### 2. Системные требования

- **Node.js**: версия `18.0.0` или выше (проверить: `node -v`)
- **npm**: версия `9.0.0` или выше (проверить: `npm -v`)
- **Python**: версия `3.9` или выше (проверить: `python3 --version`) — *требуется для работы со скриптами БД*

---

### 3. Автоматический запуск (рекомендуется)

Самый простой способ запустить веб-сайт — использовать готовый исполняемый скрипт `start.sh`:

```bash
./start.sh
```

**Что делает этот скрипт:**
1. Проверяет наличие Node.js и npm.
2. Проверяет и при необходимости автоматически инициализирует SQLite-базу `data/officials.db`.
3. Автоматически устанавливает зависимости сайта (`npm install` в папке `site`), если они ещё не установлены.
4. Запускает сервер разработки Next.js на **http://localhost:3000**.

После запуска откройте браузер и перейдите по адресу:
👉 **[http://localhost:3000](http://localhost:3000)**

---

### 4. Ручной запуск веб-портала (Next.js)

Если вы предпочитаете ручное управление через `npm`:

#### Установка зависимостей:
```bash
# Из корневой папки проекта:
npm run install:all
```
*(Или перейдите в папку `site` и выполните `npm install`)*

#### Режим разработки (Hot-Reload):
```bash
npm run dev
```
Портал будет доступен по адресу **http://localhost:3000**.
- Глобальный поиск по нажатию клавиши `/` или `Cmd+K` / `Ctrl+K`.
- Страницы всех 50 штатов с иерархией должностей и мгновенным раскрытием персоналий.
- Темная и светлая тема оформления.

#### Режим production-сборки:
```bash
npm run build
npm start
```

---

### 5. Автономный офлайн-режим (Standalone HTML)

Если вам нужен каталог без запуска Node.js-сервера:
- Просто откройте файл `dist/index.html` двойным щелчком в любом браузере (Chrome, Firefox, Safari, Edge).
- Все данные и поисковый движок уже встроены непосредственно в HTML-файл. Доступ к интернету не требуется.

Или запустите локальный мини-сервер:
```bash
python3 -m http.server 8080 --directory dist
```
И откройте в браузере **http://localhost:8080**.

## 🗄️ Работа с базой данных

### SQLite (`data/officials.db`)

В репозитории поставляется готовая реляционная база данных SQLite — `data/officials.db`. База снабжена индексами по именам, должностям, штатам и уровням юрисдикции.

#### Схема таблиц:
1. `contacts`:
   - `person_id` (PRIMARY KEY) — уникальный идентификатор.
   - `name` — имя и фамилия.
   - `role_code` — стандартизированный код должности (`GOVERNOR`, `STATE_SENATOR`, `MAYOR`, `EDA_HEAD` и т.д.).
   - `role_title` — официальное наименование должности.
   - `jurisdiction_level` — уровень (`federal`, `state`, `local`).
   - `jurisdiction_name` — название юрисдикции (штат, округ или город).
   - `parent_jurisdiction` — двухбуквенный код штата (`CA`, `TX`, `NY`...).
   - `email` — подтверждённый публичный рабочий адрес.
   - `phone` — рабочий телефон.
   - `source_url` — прямая ссылка на официальный источник верификации.
   - `status` — статус верификации (`verified`, `needs_review`).
2. `jurisdictions`: справочник всех юрисдикций США.
3. `coverage`: состояние проверки должностей по регионам.
4. `relationships`: граф субординации и взаимодействия.

---

### Примеры SQL-запросов

Вы можете работать с базой через CLI `sqlite3` или любой GUI-клиент (DBeaver, TablePlus, VS Code SQLite):

```bash
# Подключение к базе
sqlite3 data/officials.db
```

#### Поиск всех сенаторов Калифорнии с контактами:
```sql
SELECT name, role_title, email, phone, source_url
FROM contacts
WHERE parent_jurisdiction = 'CA' AND role_code = 'STATE_SENATOR'
LIMIT 10;
```

#### Статистика количества проверенных лиц по категориям должностей:
```sql
SELECT role_code, COUNT(*) AS total, SUM(CASE WHEN status = 'verified' THEN 1 ELSE 0 END) AS verified_count
FROM contacts
GROUP BY role_code
ORDER BY total DESC
LIMIT 10;
```

#### Поиск мэров крупнейших городов:
```sql
SELECT name, jurisdiction_name, email, phone, source_url
FROM contacts
WHERE role_code = 'MAYOR' AND status = 'verified'
ORDER BY jurisdiction_name;
```

### Форматы CSV и Excel

Все данные продублированы в открытых табличных форматах в папке `data/`:
- `data/contacts.csv` — основной плоский CSV-файл (кодировка UTF-8 with BOM для корректного открытия в Excel).
- `data/contacts.xlsx` — структурированная книга Excel со всеми таблицами на отдельных листах (`Contacts`, `Relationships`, `Coverage`, `Jurisdictions`).

---

### Пересборка базы данных

Если вы внесли изменения в `data/contacts.csv`:

1. **Обновить SQLite базу данных**:
   ```bash
   npm run db:init
   # или: python3 scripts/init_db.py
   ```
2. **Пересобрать автономный HTML (`dist/index.html`) и Excel (`data/contacts.xlsx`)**:
   ```bash
   npm run dist:build
   # или: python3 scripts/build.py
   ```

## 🧪 Тестирование и валидация

В проект встроен набор автоматических проверок качества и целостности данных:

```bash
# Запуск юнит-тестов (проверка структуры, схем и форматов):
npm test
# или: python3 -m unittest discover tests

# Запуск строгого валидатора контактов:
npm run validate
# или: python3 scripts/validate_contacts.py
```

Валидатор проверяет:
- Уникальность и детерминированность `person_id`.
- Корректность синтаксиса email-адресов.
- Соответствие телефонных номеров стандарту NANP (`(XXX) XXX-XXXX`).
- Валидность всех URL-адресов источников (`http://` / `https://`).
- Целостность внешних ключей в таблице связей `relationships.csv`.

## 🔒 Безопасность и публичный статус

> [!IMPORTANT]
> Репозиторий является **публичным**. В базу включены **исключительно официальные публичные служебные данные**:
> - Официальные приёмные губернаторов, сенаторов, мэров и руководителей ведомств.
> - Рабочие контактные формы и правительственные email-адреса с официальных доменов (`.gov`, `.us`).
> - В репозитории отсутствуют персональные домашние адреса, частные телефонные номера, пароли, токены или закрытые служебные секреты.
> - Служебные файлы разработчиков (`.env`, `node_modules`, кэши сборки, временные скрипты обработки) добавлены в `.gitignore` и исключены из репозитория.
