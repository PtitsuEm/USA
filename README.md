# U.S. Public Officials & Economic Development Contacts

Локальный каталог публичных служебных контактов федерального, штатного/территориального и муниципального уровней США.

## Что здесь есть

- `data/contacts.csv` — основная таблица контактов.
- `data/contacts.xlsx` — Excel-книга с листами контактов, связей, покрытия и юрисдикций.
- `data/relationships.csv` — подтверждённые связи между людьми для графа.
- `data/coverage.csv` — состояние проверки должностей по территории.
- `data/jurisdictions.csv` — справочник федерального, штатного и территориального уровня для фильтров приложения.
- `scripts/build.py` — собирает CSV-файлы в автономную HTML-страницу.
- `dist/index.html` — приложение, открываемое локально в браузере; оно не обращается к серверу или сторонним API.
- `PROJECT_SPEC.md` — границы проекта, определения и правила проверки.
- `SOURCE_WORKBOOK_AUDIT.md` — разбор дополнительной таблицы на 2 287 строк.
- `VALIDATION.md` — результат офлайн-проверки формата email и телефонов.

## Запуск

1. Откройте `dist/index.html` двойным щелчком.
2. После изменения CSV пересоберите страницу:

   ```sh
   python3 scripts/build.py
   ```

Требуется только Python 3. Данные приложения встроены в HTML при сборке, поэтому страница работает офлайн.

## Обновление данных

Для каждой записи указывайте официальный источник и дату проверки. Не добавляйте предполагаемые адреса электронной почты как подтверждённые. LinkedIn-профиль добавляйте только при надёжном совпадении личности.

Для обновления контактных лидов из SelectUSA:

```sh
python3 scripts/import_selectusa.py --refresh-selectusa
python3 scripts/build.py
```

Импортёр получает текущую версию каталога SelectUSA, обновляет только записи с префиксом `selectusa-` и оставляет их со статусом `needs_review`.

GitHub-репозиторий хранит коммиты и версии файлов. Если репозиторий публичный, опубликованные в нём контакты будут доступны всем.

## Текущий статус

В основной базе **278 уникальных контактов**: 223 подтверждены по официальным источникам (`verified`), 55 остаются на проверке (`needs_review`). В 63 записях указана опубликованная почта, в 163 — подтверждённый телефон приёмной. Форматная проверка не подтверждает доступность почтового ящика или телефонной линии.

Полностью верифицированы по официальным источникам:
- **55 губернаторов (`GOVERNOR`)**: статус `verified`, официальные URL приёмных и контактных веб-форм для всех 50 штатов и 5 территорий.
- **55 вице-губернаторов и конституционных преемников (`GOVERNOR_DEPUTY`)**: статус `verified`, официальные порталы и подтверждённые публичные email-адреса. Для штатов без отдельной должности вице-губернатора зафиксированы конституционные преемники (государственные секретари или председатели сенатов).
- **56 руководителей агентств экономического развития (`EDA_HEAD`)**: статус `verified`, официальные порталы ведомств и опубликованные телефоны по всем 50 штатам, 5 территориям и округу Колумбия (DMPED).
- **53 мэра городов (`MAYOR`)**: статус `verified`, 50 крупнейших мегаполисов США и столиц штатов + 3 пилотных города Делавэра с официальными городскими порталами и телефонами мэрий.
- **111 подтверждённых связей (`relationships.csv`)**: 55 связей `coordinates_with` (вице-губернатор -> губернатор), 55 связей `reports_to`/`coordinates_with` (руководитель EDA -> губернатор), 1 связь `reports_to` (руководитель DMPED -> мэр Вашингтона, О.К.). Активирован интерактивный SVG-граф связей в локальном приложении `dist/index.html`.

В пилоте по Делавэру добавлены подтверждённые записи руководства штата и муниципалитетов, а также перечень всех 57 муниципалитетов. Покрытие должностей мэра и заместителя мэра в муниципалитетах отмечено отдельно; незаполненные города остаются `in_progress`.

Файл `US_Government_and_Economic_Leadership.xlsx` содержит 2 287 строк, но в нём найдены неподтверждённые данные и LinkedIn-ссылки на поиск. Он сохранён как исходный материал; строки переносятся в основную базу только после отдельной проверки. Детали — в `SOURCE_WORKBOOK_AUDIT.md`.

Из файла отдельно проверена и добавлена Kelly Cummins (DOE OCED). В базу перенесены только имя и должность, которые подтверждает текущая официальная биография; неподтверждённые почта, телефон и LinkedIn оставлены пустыми.
