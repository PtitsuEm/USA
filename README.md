# U.S. Public Officials & Economic Development Contacts

Локальный каталог публичных служебных контактов федерального, штатного/территориального и муниципального уровней США.

## Что здесь есть

- `data/contacts.csv` — основная таблица контактов.
- `data/contacts.xlsx` — Excel-книга с листами контактов, связей, покрытия и юрисдикций.
- `data/relationships.csv` — подтверждённые связи между людьми для графа.
- `data/coverage.csv` — состояние проверки должностей по территории.
- `data/jurisdictions.csv` — справочник федерального, штатного и территориального уровня для фильтров приложения.
- `scripts/build.py` — собирает CSV-файлы в автономную HTML-страницу.
- `dist/index.html` — приложение, открываемое локально в браузере; оно не обращается к серверу или сторонним API.
- `PROJECT_SPEC.md` — границы проекта, определения и правила проверки.

## Запуск

1. Откройте `dist/index.html` двойным щелчком.
2. После изменения CSV пересоберите страницу:

   ```sh
   python3 scripts/build.py
   ```

Требуется только Python 3. Данные приложения встроены в HTML при сборке, поэтому страница работает офлайн.

## Обновление данных

Для каждой записи указывайте официальный источник и дату проверки. Не добавляйте предполагаемые адреса электронной почты как подтверждённые. LinkedIn-профиль добавляйте только при надёжном совпадении личности.

Для обновления контактных лидов из SelectUSA:

```sh
python3 scripts/import_selectusa.py --refresh-selectusa
python3 scripts/build.py
```

Импортёр получает текущую версию каталога SelectUSA, обновляет только записи с префиксом `selectusa-` и оставляет их со статусом `needs_review`.

GitHub-репозиторий хранит коммиты и версии файлов. Если репозиторий публичный, опубликованные в нём контакты будут доступны всем.

## Текущий статус

Создана структура базы и автономный интерфейс навигации. Внесены 56 предварительных инвестиционных контактных точек из SelectUSA: 50 штатов, 5 территорий и округ Колумбия (со статусом `needs_review`). Все 55 губернаторов (50 штатов и 5 территорий) верифицированы по официальным правительственным порталам штатов и территорий: для каждого указан актуальный официальный URL приёмной/веб-формы, дата проверки 2026-10-15 и статус `verified` (включая опубликованный служебный email губернатора Колорадо; для остальных органов власти почта и LinkedIn не домысливались в соответствии с правилами проекта). Полный список ролей и муниципалитетов находится в стадии формирования.
